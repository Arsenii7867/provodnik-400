## Исправления

| Проблема | Результат |
| --- | --- |
| Продакшен принимал опубликованный демо-ключ | Пустой и известный демо-ключ запрещены при `APP_ENV=prod` |
| Переход dev-базы в prod оставлял PIN 1234 у синтетических сотрудников | Старт отклоняется, даже при отключённом автосиде; база не переписывается |
| Нефинитный допуск таймера и неположительные настройки безопасности | Конфигурация отклоняется при запуске |
| Старые ключи неудачных входов оставались в памяти | Добавлена периодическая очистка истёкших записей |
| Прямой `/index.html` отдавался без CSP | Применяется та же политика, что для остальных SPA-страниц |
| Ключ повторного старта принимал другой класс обслуживания | Явное изменение класса возвращает 409; одинаковый запрос без класса сохраняет старое прохождение после правки YAML |
| Автообновление каталога поглощало событие нового сценария | Принудительное перечитывание сравнивает с последней сообщённой версией |
| Истечение таймера зависало после временного сетевого сбоя | Повтор с паузой, отмена при уходе/смене шага; обрыв чтения тела ответа тоже считается сетевой ошибкой |
| Одновременные отметки уведомлений перетирали друг друга | Функциональное обновление состояния сохраняет обе отметки |
| Отозванный токен не всегда возвращал на вход | Подписка на изменение токена; поздний ответ старого входа не удаляет новый токен |
| Смена класса после потерянного ответа сохраняла старый ключ старта | Новый ключ привязан к выбранному классу |
| Шкалы XP не имели доступного имени и корректной верхней границы | Добавлены имена и процентные значения |
| Уязвимая версия React Router | Зафиксирована `react-router-dom` 7.18.4 и обновлён lockfile |
| Инструкция запускала сервер до сборки фронта и не загружала `.env` явно | Уточнены порядок сборки, путь env-файла и автосид |
| Авторские медицинские пояснения представлялись как нормы | Четыре пояснения уточнены без изменения игровой логики; восстановлен полный совет карточки 29 |

- npm audit после обновления: 0 известных уязвимостей, включая dev-зависимости.
- Gitleaks 8.30.1: проверены история и рабочее дерево. В каждом отчёте восемь срабатываний
  `curl-auth-header` в примерах `docs/api.md`: все относятся к публичному значению
  `demo-integration-key`. Это демо-значение, теперь явно запрещённое в prod; других находок нет.
  История ради удаления этих примеров не переписывалась.
- Создан CycloneDX SBOM и выполнен разбор графа установленным SBOM-скиллом. Прямые запросы
  этого скрипта в NVD отключены (`--skip-nvd`); CVE-проверка выполнена Trivy/npm. Нулевой
  офлайн-риск в выводе SBOM-скрипта не используется как доказательство безопасности.
  Метаданные лицензий неполны, юридическая проверка лицензий не выполнена.
- Добавлены шесть браузерных регрессий восстановления. Локальное исполнение заблокировано:
  macOS sandbox завершает Chrome/headless shell при запуске (EPERM/SIGTRAP). Встроенный
  браузер также не открыл localhost. Обнаружение всех 12 браузерных тестов выполнено отдельно от исполнения.
  Полный `scripts/check.sh` до зелёного браузерного этапа на этом Mac не доведён.
  На GitHub запущена независимая Linux-проверка с Chromium; её итог относится к ревизии,
  указанной в Actions, и не подменяется локальными результатами.

Пять пропусков Python-тестов — неприменимые к отдельным сценариям проверки ожидаемой
эскалации. Остаётся предупреждение Starlette о будущей замене httpx в TestClient; оно не
является падением тестов.

## Метод проверки

Применены Superpowers (план, воспроизведение, регрессии, независимое ревью и проверка перед
завершением), security-review, verification-loop, инструкции Semgrep и SBOM. Ponytail,
Ponytail Audit и Ponytail Review взяты из
[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) на ревизии
`e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156`: изменения сохраняют существующую архитектуру,
не вводят фреймворков, общих фабрик или ненужных обёрток. Смысловые комментарии, проверки
безопасности и тесты не удалялись ради сокращения строк. Независимое ревью нашло ещё два
пограничных случая — изменение YAML между повторами старта и обрыв тела HTTP-ответа;
оба воспроизведены тестами и исправлены.

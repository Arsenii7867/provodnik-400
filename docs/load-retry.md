# Восстановление загрузки экрана

При сетевом сбое экран показывал ошибку без возможности повторить запрос.
Теперь кнопка «Повторить» заново загружает текущий ресурс, сохраняя маршрут
и фильтры. На время запроса кнопка недоступна; после очередного сбоя остаётся
возможность повторить загрузку.

Общий компонент `LoadError` вызывает `reload` из `useLoad`. Начальная загрузка
прохождения повторяется внутри `PlayRun` для того же `runId`. Ответы после ухода
с экрана не применяются. Механизм не повторяет выбор ответа или запуск сценария;
автоматического повтора POST нет.

Правила времени, начислений и завершения сохраняются. Если серверный дедлайн
прошёл во время восстановления, действует обычная обработка истечения, включая
запрос `expire`. Вопросы о технических сбоях и старте таймера вынесены в roadmap.md.

## Проверка

Регрессии в frontend/e2e/load-retry.spec.js проверяют:

- сетевой сбой каталога, ответ 503 при повторе, блокировку кнопки и следующую
  успешную загрузку с сохранением фильтра;
- восстановление общего профиля и имени в шапке;
- восстановление того же прохождения и текущего хода.

Во всех трёх сценариях документ браузера сохраняется, дополнительных записывающих
API-запросов нет. Прохождение проверяется до истечения дедлайна. До изменения
тест каталога падал из-за отсутствия кнопки.

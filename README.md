# Проводник 400

Тренажёр нештатных ситуаций для проводников ВСМ-400: сотрудник проходит ветвящиеся сценарии,
принимает решения под серверным таймером и видит, как каждое решение двигает две шкалы,
лояльность пассажира и рейтинг безопасности. Сценарии лежат в YAML и меняются без пересборки.

## Как запустить

Сервер (Python 3.13), из папки `backend`:

```
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Проверка: `http://127.0.0.1:8000/api/health` отвечает JSON со статусом `ok`,
описание API на `http://127.0.0.1:8000/docs`.

Фронт (node 22 и новее), из папки `frontend`:

```
npm ci
npm run build
```

Собранный `frontend/dist` сервер раздаёт сам на порту 8000. Для разработки `npm run dev`
поднимает Vite на 5173 с прокси запросов `/api` на сервер.

## Где что лежит

| Путь | Что там |
|---|---|
| `backend/app` | сервер на FastAPI: настройки, единый формат ошибок, маршруты |
| `backend/tests` | тесты pytest на временной SQLite |
| `frontend/src` | интерфейс на React, данные только через `src/lib/api.js` |
| `frontend/e2e` | сквозные проверки Playwright |
| `scripts/check.sh` | все проверки одной командой: тесты, ruff, сборка фронта |
| `.env.example` | переменные окружения с пояснениями |

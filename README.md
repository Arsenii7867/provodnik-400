# Проводник 400

Тренажёр нештатных ситуаций для проводников ВСМ-400: сотрудник проходит ветвящиеся сценарии,
принимает решения под серверным таймером и видит, как каждое решение двигает две шкалы,
лояльность пассажира и рейтинг безопасности. Сценарии лежат в YAML и меняются без пересборки.

## Как запустить

Сервер (Python 3.13), из папки `backend`:

```
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m app.seed
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers
```

Проверка: `http://127.0.0.1:8000/api/health` отвечает JSON со статусом `ok`,
описание API на `http://127.0.0.1:8000/docs` (Swagger UI отдаётся с самого сервера, без
внешних адресов). Демо-вход: коды `VSM-1001` и `VSM-1002` (проводники), `VSM-2001`
(наставник), PIN `1234` (переменная `DEMO_PIN`). Все сотрудники синтетические. Сид
идемпотентен, при `AUTO_SEED=1` сервер сам заполняет пустую базу. Флаг `--no-proxy-headers`
запрещает uvicorn верить заголовку `X-Forwarded-For`: лимит попыток входа считает адреса
соединений, а не то, что прислал клиент; за доверенным прокси флаг убирают.

Тесты и линтер живут в отдельном файле зависимостей, из папки `backend`:

```
.venv/Scripts/pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest -q
.venv/Scripts/python -m app.scenarios.validator ../content
```

Все проверки разом (тесты, ruff, валидатор сценариев, тесты и сборка фронта) запускает
`scripts/check.sh` из корня репозитория.

Фронт (node 22 и новее), из папки `frontend`:

```
npm ci
npm run build
```

Собранный `frontend/dist` сервер раздаёт сам на порту 8000. Для разработки `npm run dev`
поднимает Vite на 5173 с прокси запросов `/api` на сервер.

## Где что лежит

| Путь | Что там |
|---|---|
| `backend/app` | сервер на FastAPI: настройки, база, вход по коду и PIN, единый формат ошибок, маршруты в `api` |
| `backend/app/scenarios` | движок прохождения, загрузчик, валидатор, перебор путей, граф и хранилище контента с перечитыванием |
| `backend/app/services` | прохождение с серверными таймерами, подсчёт результата: XP, уровни, владение компетенциями |
| `backend/tests` | тесты pytest на временной SQLite, сломанные сценарии в `tests/fixtures/broken` |
| `content` | справочники и сценарии в YAML, описание формата в `docs/scenarios.md` |
| `frontend/src` | интерфейс на React, данные только через `src/lib/api.js` |
| `frontend/e2e` | сквозные проверки Playwright |
| `scripts/check.sh` | все проверки одной командой: тесты, ruff, сборка фронта |
| `.env.example` | переменные окружения с пояснениями |
